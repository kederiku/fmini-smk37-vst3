# Changelog / Historique

## 0.1.0 — 2026-11-17

### English

- Initial Windows x64 VST3 port of the FMini-1 SMK-37 emulator.
- Native panel, original firmware display/audio, host MIDI input and state recall.
- Sample-rate adaptation, independent instances, continuous output automation and channel-aware sustain.
- English/French user and developer documentation; English code comments.
- GitHub Actions build/test/package workflow and tag-triggered draft releases.
- Public packages include complete corresponding sources; optional SAVIHost packaging is separate.

### Français

- Premier portage VST3 Windows x64 de l'émulateur FMini-1 SMK-37.
- Panneau natif, écran/son d'origine, entrée MIDI et rappel d'état par l'hôte.
- Adaptation des fréquences, instances indépendantes, automation continue du gain et sustain par canal.
- Documentation utilisateur/développeur en français et anglais ; commentaires du code en anglais.
- Compilation/tests/paquets avec GitHub Actions et releases en brouillon déclenchées par tag.
- Sources correspondantes complètes dans les paquets publics ; paquet SAVIHost facultatif séparé.
